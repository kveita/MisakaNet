## 2. 根因（详见 docs/maintainer/dco-experience-issue-1498.md）

1. `needs-dco` 标签**只加不删**：`pr-shape-guard.yml` Gate 4 仅在未签时 add，
   全仓无任何 `removeLabel('needs-dco')`；`pr-quality-gate.yml` 反把残留标签当
   `ready-to-merge` 硬阻断 → 修好后永久红标。
2. 三套 DCO 实现语义分裂（dco-check 含 merge 提交 / dco-audit `--no-merges` /
   shape-guard 含 merge 提交）→ 误判源。
3. 失败评论只追加不清扫（REGULATORY BLOCK + 逐次 audit 报告）→ 界面自相矛盾。
